# Security Policy

`c-code-score` is a single-file, dependency-free static-analysis helper. It
does not execute the C code it analyzes and does not open network connections.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately via
[GitHub Security Advisories](https://github.com/xtforever/c-score/security/advisories/new)
instead of a public issue. Reports are acknowledged as soon as possible.

## Supported Versions

Only the latest release is supported.
